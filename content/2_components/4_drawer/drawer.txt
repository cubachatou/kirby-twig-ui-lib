Title: Drawer

----

Excerpt: Bottom-sheet and side-panel drawer built on the Popover API. Drag-to-dismiss, multiple sides, and a responsive Vaul-style mode included.

----

Intro: <p>A sliding drawer component built on the Popover API (<code>popover="manual"</code>). Slides in from any edge of the viewport. Supports drag-to-dismiss gestures, scrollable content, and a responsive mode that switches from a bottom sheet on mobile to a centered modal on desktop — a vanilla-JS equivalent of Vaul.</p>
