Title: Dialog

----

Excerpt: Accessible modal dialog built on the native <dialog> element. Focus trap, Escape key, and backdrop handling out of the box.

----

Intro: <p>A modal dialog component built on the native <code>&lt;dialog&gt;</code> element. It gets a focus trap, Escape key handling, and backdrop rendering for free — no ARIA hacks required. Four variants cover the most common patterns: default, custom close, no close, sticky footer, and scrollable content.</p>
