Title: Carousel

----

Excerpt: Touch-friendly, accessible image carousel powered by Swiper.js v12. Navigation, pagination, autoplay, and loop via Panel toggles.

----

Intro: <p>A slide carousel built on top of <a href="https://swiperjs.com">Swiper.js v12</a>. Drop it into any blocks field, add slides in the Panel, and enable features — navigation arrows, dot indicators, autoplay, infinite loop — with a single toggle. No configuration in code required.</p>
