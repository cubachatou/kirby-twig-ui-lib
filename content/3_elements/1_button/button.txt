Title: Button

----

Excerpt: Zero-JS, CSS-only button primitive. Six variants, four sizes, icon support. Drop into any Twig template with a single include.

----

Intro: <p>A reusable <code>&lt;button&gt;</code> element built as a Twig snippet partial. No JavaScript, no framework opinions. All states — hover, focus, active, disabled — are driven by CSS and HTML attributes. Include it anywhere in a Twig template with a single <code>{% include %}</code> call.</p>
